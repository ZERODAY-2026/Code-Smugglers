# UCI Bank Marketing dataset

The canonical DataMind demo source is:

```text
datasets/bank/bank-full.csv
```

It is the UCI Bank Marketing dataset (`bank-full.csv`), containing 45,211
source rows and 17 columns. The file is semicolon-delimited and includes the
original target column `y`.

Dataset source: [UCI Machine Learning Repository - Bank Marketing](https://archive.ics.uci.edu/dataset/222/bank+marketing).

The source documentation is retained in
[`bank-names.txt`](./bank/bank-names.txt). The dataset must be loaded into
Snowflake before DataMind can query it. The application must never calculate
answers from this local file or invent replacement values.

The repository ignores the downloaded data files. Run
[`scripts/load_bank_marketing.py`](../scripts/load_bank_marketing.py) to copy
the source values into:

```text
DATAMIND.BANK_MARKETING.BANK_MARKETING
```

The script checks the source header and verifies that Snowflake loaded exactly
the same number of rows as the source file.

The current Snowflake load was verified with `COUNT(*) = 45211`. A live
grouping query returned `y = no: 39922` and `y = yes: 5289`, with a Snowflake
query ID. These numbers are evidence from Snowflake, not values generated by
the application.

The source field `default` is stored as `DEFAULT_VALUE` in Snowflake to avoid
reserved-word ambiguity in generated SQL. Its values are copied unchanged.
